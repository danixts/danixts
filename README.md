### 🚀 What I'm building

- **Event-driven microservices** in Go using hexagonal architecture, multi-tenant by design, communicating over NATS (canonical events + request/reply).
- **AI services** — LLM agents, a Model Context Protocol knowledge server, and RAG pipelines over Qdrant scoped per tenant.
- **Plugin ecosystem** — composable Go plugins (bot, calendar, transform, QR, Telegram) wired behind a KrakenD API gateway.
- **Web platform** — multi-tenant Astro SSR storefront and Vue admin dashboards.
