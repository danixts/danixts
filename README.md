### 🚀 En qué trabajo

- **Microservicios orientados a eventos** en Go con arquitectura hexagonal, multi-tenant de raíz, comunicándose por NATS (eventos canónicos + request/reply).
- **Servicios de IA** — agentes LLM, un servidor de conocimiento con Model Context Protocol y pipelines RAG sobre Qdrant aislados por tenant.
- **Ecosistema de plugins** — plugins de Go componibles (bot, calendario, transform, QR, Telegram) detrás de un API gateway con KrakenD.
- **Plataforma web** — storefront SSR multi-tenant en Astro y dashboards de administración en Vue.
